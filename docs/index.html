🧠 Teachable Machine

Es una herramienta de Google que te permite crear modelos de Inteligencia Artificial sin escribir código. Usas tu cámara para enseñar a la IA a reconocer objetos, posturas o sonidos.

¿Cómo se usa aquí? Entrena tu modelo, haz clic en "Exportar", sube el modelo a la nube y pega el enlace generado en el recuadro de abajo.

⚙️ Micro:bit & MakeCode

MakeCode es la plataforma de Microsoft para programar la tarjeta Micro:bit usando bloques lógicos. Ideal para crear proyectos de robótica e IoT.

¿Cómo se usa aquí? Programa tu Micro:bit con el bloque bluetooth start uart service y on data received. Esta web enviará la predicción de la IA a tu tarjeta vía Bluetooth.
