# Modelos 3D

Estos modelos fueron diseñados para facilitar el montaje del proyecto ServoBLE.

## Archivos

### Base del Servo

Permite fijar el servomotor SG90 al prototipo.

Material recomendado

- PLA
- Altura de capa: 0.2 mm
- Relleno: 15%

---

### Barra

El servomotor controla una barra de acceso, simulando un sistema utilizado en estacionamientos, condominios y puntos de control vehicular.

Material recomendado

- PLA
- Altura de capa: 0.2 mm
- Relleno: 15%
